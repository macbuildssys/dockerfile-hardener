# DH004 — MultiStage

**Severity:** 🟡 MEDIUM
**Auto-fix:** ✗ No
**Tags:** Docker-Hardening, Attack-Surface, Image-Size

---

## What this rule checks

Dockerfiles that compile code (Go, C/C++, Rust, Java, etc.) must use
multi-stage builds. A single-stage build that installs a compiler, builds
the binary, and then serves it ships the entire build toolchain alongside
the application.

Specifically flagged indicators in single-stage builds:

- Installation of build tools: `gcc`, `g++`, `clang`, `make`, `cmake`,
  `cargo`, `go`, `javac`, `maven`, `gradle`, `dotnet`, `build-essential`
- Execution of build commands: `go build`, `cargo build`, `make`,
  `mvn package`, `gradle build`, `dotnet publish`
- `COPY` of source files with compiled-language extensions:
  `.go`, `.rs`, `.c`, `.cpp`, `.java`, `.cs`

---

## Why it matters

Shipping compilers and build tools in the production image:

- **Increases attack surface** — a compiler is a powerful tool for an
  attacker who has gained code execution; they can compile and run
  arbitrary binaries without fetching external tools.
- **Increases image size** — build toolchains are large. A Go binary in
  a distroless image might be 10 MB; the same image with `golang` included
  is 800 MB+.
- **Ships source code** — if source files are copied into the image,
  they are readable by anyone with image access.

---

## Failing example

```dockerfile
FROM golang:1.22
WORKDIR /app
COPY . .
RUN go build -o server .
CMD ["./server"]
# Ships the Go toolchain (~800 MB) + source code
```

---

## Passing example

```dockerfile
FROM golang:1.22.2 AS builder
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -o /out/server .

FROM gcr.io/distroless/static-debian12:nonroot
COPY --from=builder /out/server /server
CMD ["/server"]
# Final image: ~10 MB, no toolchain, no source
```

## Other language examples

**Python** (no compiler needed, but still worth separating deps):
```dockerfile
FROM python:3.12.3-slim AS builder
COPY requirements.txt .
RUN pip install --prefix=/install -r requirements.txt

FROM python:3.12.3-slim
COPY --from=builder /install /usr/local
COPY app/ /app/
USER nonroot
CMD ["python", "-m", "app"]
```

**Rust:**
```dockerfile
FROM rust:1.77.2 AS builder
WORKDIR /app
COPY . .
RUN cargo build --release

FROM gcr.io/distroless/cc-debian12:nonroot
COPY --from=builder /app/target/release/myapp /myapp
CMD ["/myapp"]
```
