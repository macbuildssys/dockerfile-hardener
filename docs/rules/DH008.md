# DH008 — AptHygiene

**Severity:** 🟡 MEDIUM (cache/recommends); 🔵 LOW (version pinning)
**Auto-fix:** ✔ Yes (cache cleanup and --no-install-recommends)
**Tags:** Docker-Best-Practice, Image-Size, Reproducibility

---

## What this rule checks

`RUN` instructions that install packages via `apt-get` or `apk` are checked
for four hygiene issues:

| Issue | Severity | Fixable |
|---|---|---|
| No cache cleanup (`rm -rf /var/lib/apt/lists/*`) | MEDIUM | ✔ |
| Missing `--no-install-recommends` | MEDIUM | ✔ |
| `apt-get update` without `apt-get install` in same layer | MEDIUM | ✗ |
| No version pinning | LOW | ✗ |
| `apk add` without `--no-cache` | MEDIUM | ✔ |

---

## Why each check matters

**Cache cleanup** — `apt-get` stores downloaded package indexes and `.deb`
files in `/var/lib/apt/lists/` and `/var/cache/apt/`. These persist in the
image layer unless removed in the same `RUN` instruction. Running
`rm -rf /var/lib/apt/lists/*` in a separate `RUN` creates a new layer on
top but the data is still in the earlier layer.

**`--no-install-recommends`** — apt installs not just requested packages
but also their "recommended" packages by default. Recommended packages are
often documentation, optional utilities, and GUI tools that have no place in
a container. Omitting this flag can silently add dozens of packages.

**Stale cache** — if `apt-get update` runs in one `RUN` layer and
`apt-get install` runs in a later layer, Docker's build cache may serve the
update layer from cache on a rebuild while re-running the install with a
stale package index. Always combine update and install in a single `RUN`.

**Version pinning** — without explicit versions, two builds on different
days may install different package versions, breaking reproducibility.

---

## Failing examples

```dockerfile
# Cache not cleaned, no --no-install-recommends, update and install split
RUN apt-get update
RUN apt-get install -y curl vim
```

```dockerfile
# apk without --no-cache
RUN apk add curl bash
```

---

## Passing examples

```dockerfile
# apt-get — fully hygiene-compliant
RUN apt-get update \
    && apt-get install -y --no-install-recommends \
        curl=7.88.1-10+deb12u5 \
        ca-certificates=20230311 \
    && rm -rf /var/lib/apt/lists/*
```

```dockerfile
# apk — use --no-cache
RUN apk add --no-cache curl=8.5.0-r0 ca-certificates=20240226-r0
```

```dockerfile
# apk — alternative: virtual group + del
RUN apk add --virtual .build-deps gcc musl-dev \
    && make \
    && apk del .build-deps
```

---

## Auto-fix behaviour

`--fix` appends `&& rm -rf /var/lib/apt/lists/*` to `apt-get install`
instructions missing cache cleanup, and adds `--no-install-recommends`
where missing. Version pinning and stale-cache issues require manual
intervention.
